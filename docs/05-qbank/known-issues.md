# QBank — Known Issues (full)

1. **Corpus lag** — new questions appear only in releases; "missing latest semester" is normal, not broken — check the release tag.
2. **OCR-formatted papers** — some papers are OCR'd; math errors happen — anomalies reported via feedback are moderated before release.
3. **Copyright edge** — VIT holds exam paper rights; this stays in beta until legal clearance per campus notice.
4. **Answers not verified** — model answers are community-submitted; treat as hints, not gospel; the feedback link corrects wrong ones.
