# Marks Predictor — Overview (the walkthrough)

> **In one line:** "I have 61 in CAT2 — tell me if I still have a shot at an A."

Flow:

1. **Academics → Marks Predictor** — enrolled courses listed; pick one (or add a virtual "custom" course)
2. **Edit assessments** — real components pre-loaded from the last VTOP marks pull (but you can edit anything)
3. **Watch the ladder** — letters with points and the FAT score needed for each, computed live
4. **Class curve?** — if cohort stats are in (you've synced at least once), relative-grading rows appear
5. **Override assumptions** — μ/σ sliders per course ("assume the class did terrible")
6. **Decide** — "I need 37/40 on FAT to guarantee A; pass to sleep well: 22." It prints pass/bonus/safe.

## What it isn't

- Not a gradebook — it doesn't re-read VTOP on every keystroke
- Not deterministic for relative grading — the curve depends on real class behavior; σ estimates
  age rapidly. Treat relative rows as "intelligence, not prophecy"
- Not the place where soft-skill 10s are decided — your faculty decides those; we just compute ladders
