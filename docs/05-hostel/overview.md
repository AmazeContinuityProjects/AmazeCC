# Hostel — Overview (walkthrough)

> **In one line:** every hostel night's answer in one tab — what's for dinner, when's laundry, what's your leave status, where's your ride.

1. **Today's mess** — remaining meals in the canteen (countdown chips); tomorrow preview below
2. **Laundry** — your block's day, hours, venue
3. **Leaves** — approved/pending/rejected status; "Apply" button opens the portal
4. **Counselling** — slot reminders + official portal link for booking
5. **Cab share** — ride pool: post your drop/pickup; see who's going tomorrow; accept/decline; your identity only visible to acceptor

Freshmen see different copy — onboarding carries them to the tab on first hosteller login.
