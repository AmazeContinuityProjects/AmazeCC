# FFCS Friends — Known Issues (full)

1. **Handle collision banner** — if a peer changes their handle, old pairs silently stop refreshing; manual re-add required.
2. **Handles expire** —毕业 alumni get culled during server cleanup; their cards go grey with "left VIT".
3. **Busy map only, unless full** — overlaps render as occupied chunks; course identities hidden unless both sides opted full.
4. **Group limits** — soft cap 12 per group; beyond that the intersection math gets unreadable anyway.
5. **Pairing requires refresh on both sides** — first match renders after the next sync on either device, not on pair-complete.
