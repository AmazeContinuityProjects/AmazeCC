# Student Report — Overview (walkthrough)

> **In one line:** one tap — "everything VIT knows about my academics, in a PDF you can email your parents".

1. **Settings → Account → Export Report** — pick sections: grades/attendance/predictions/timetable
2. Generation takes 3–8 seconds on mobile (no network)
3. Preview page: scroll through; every page branded AmazeCC with your reg number watermark
4. Options: PDF download · print · skip predictions (off for parent-facing copies)

Use case: parent-teacher conference prep; your own semester reflection; scholarship applications.
