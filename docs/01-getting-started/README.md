# 01 — Getting Started (your first hour)

> **Reading time:** ~5 min. **Prereqs:** none.

This section takes you from zero to a running app in demo mode. Nothing here requires a VIT
account, a VTOP login, or network access beyond GitHub + npm.

## The 15-minute path

1. **[01-prerequisites](01-prerequisites.md)** — install git, Node 22, pnpm
2. **[02-clone-and-install](02-clone-and-install.md)** — get the code, install deps (~3 min)
3. **[04-run-in-demo-mode](04-run-in-demo-mode.md)** — see the full app populated with demo data
4. **[05-your-first-change](05-your-first-change.md)** — edit one string; see it live; commit

Then keep handy:

- **[03-env-vars](03-env-vars.md)** — what every `NEXT_PUBLIC_*` does; all can be blank for demo
- **[06-scripts](06-scripts.md)** — every `pnpm` command explained
- **[07-running-tests](07-running-tests.md)** — run a suite; run all of them
- **[08-building-for-production](08-building-for-production.md)** — how the site ships
- **[09-handoff-checklist](09-handoff-checklist.md)** — what you're expected to own

## If you only remember three things

- `pnpm install` — never `npm install`
- Demo mode is your workshop — build a whole fluency on it before touching live paths
- The web Foundation section (`../00-web-foundation/README.md`) is the real prerequisite —
  if anything in this section is opaque, the primer pages explain _why_ it works that way
