# Settings & Profile — Overview (walkthrough)

> **In one line:** the entire app's knobs in one place — personalize once, never touch again.

1. **Profile** — your photo, name, branch, academic goal (pointer: GPA target drives predictor badges)
2. **Sync** — mode picker; see last sync time; one-tap force sync
3. **Appearance** — dark/light/midnight, palette (5 accent choices), font size
4. **Privacy** — blur grades/attendance in public view; force-incognito-delete on tab close
5. **Advanced** — API host override (for devs); custom API URL; nuclear reset button (full data wipe + logout)

Entry points: header avatar → Settings; every screen deep-links here from its own settings gear.
