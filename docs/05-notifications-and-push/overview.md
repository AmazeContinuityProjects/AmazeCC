# Notifications & Push — Overview (walkthrough)

> **In one line:** you choose exactly which pings; silence is the default.

1. **Settings → Notifications** — list: marks posted, attendance low, deadlines, POM checkpoints, app news
2. **Toggle any** — switch on/off per category; test push per category available (dev builds only)
3. **Quiet hours** — 22:30–07:30 default; pick yours; OS focus modes still respected!

Push doesn't replace VTOP — VIT's notifications are famously terrible; these are _better_ ones from the same data.
