# Marks & Cohort — Overview (in plain language)

> **In one line:** donate your anonymized scores so the app can tell you the class curve — never without your click.

1. **Settings → Academic → Contribute to class statistics** — the one and only switch.
2. Nothing else is needed. Every marks sync thereafter contributes — silently if you want.
3. In the academics tab, FAT rows now show "class average: μ, top 25% within σ".
4. Opt out any time — your stored receipts are unused; no server-side deletion needed (we never held identity).

Security/privacy details live in `11-security/04-identity-verification.md` and `05-marks-and-cohort/architecture.md` — this tab is the summary, not the contract.
