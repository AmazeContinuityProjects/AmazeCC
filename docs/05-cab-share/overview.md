# Cab Share — Overview (walkthrough)

> **In one line:** split a cab with classmates who actually need to go the same route, at the same time.

1. **Cab Share tab** (Hostel → Cab Share) — two halves: "Finding a ride?" and "Posting a ride?"
2. Post your trip: from–to picks (curated list of 12 common VIT routes — home/hostel/transit), time picker, seats, note
3. Browsing: peers' active posts; tap for detail: time, pickup point near campus, seats left
4. Request → accept → both see each other's contact only now
5. Post-trip completion: both confirm → stored history pruning optional

Privacy: nobody sees your phone number until you both manually share it inside the accepted request sheet.
