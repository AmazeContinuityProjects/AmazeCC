# Feedback & Support — Overview (walkthrough)

> **In one line:** something's broken — tell us what, and we fix it, in minutes where possible.

1. **Floating bar appears** — only when you manually tap it — never unsolicited
2. **Describe the issue** — free text; "slow", "crashed", "wrong number" — any of these is gold
3. **Attach tech info?** — yes, always — sha helps us find the exact code
4. **Send** — reference code shown; check back anytime; maintainer usually replies same day

Also reachable from every error screen's "Report this bug" button with context pre-filled.
