# Tasks & Pomodoro — Overview (walkthrough)

> **In one line:** everything on your plate this week, plus a timer that doesn't let you escape it.

1. **Tasks tab** — three views toggle: List / Kanban / Week
2. **Add task** — quick add floating button; picks due date, course, pomodoro estimate
3. **Start a pomodoro** — tap the timer → full-screen focus mode (task title, countdown, "stop" = save progress)
4. **Import Moodle deadlines** — tap import; previews matched against your timetable; approve → populated board
5. **Kanban** — drag pending → in-progress → done; done items archive for the export report
6. **Week view** — chunked chunks; collisions show red overlap markers

Demo mode ships no tasks — they persist locally per browser; add freely.
