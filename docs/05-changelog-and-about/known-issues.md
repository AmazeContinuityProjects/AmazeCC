# Changelog & About — Known Issues (full)

1. **Version shown = GitHub sha, not CDN** — check "build #" with Settings → About if in doubt; assets the CDN hasn't propagated yet can lag by minutes.
2. **Changelog gaps** — small fixes skip changelog entries by maintainer choice; the About footer shows the sha; git log is the full record.
3. **Favicon mismatch mid-deploy** — during a rollout, some tabs keep old icons briefly — refresh once, not a bug.
4. **Attribution leak** — vendored sources noted where required; do email us if you spot a missing license mention.
