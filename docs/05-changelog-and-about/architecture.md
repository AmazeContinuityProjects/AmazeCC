# Changelog & About — Architecture (deep)

> **In one line:** version history for people, sha-based build identity for humans who want proof.

## 1. The changelog file

`src/data/changelog.json` — `{ version, date, title, changes[] }` — rendered by `ChangelogModal.tsx`.
Updated per release; dates real; titles match git tag where applicable.

## 2. buildInfo

`src/data/buildInfo.json` — generated by `scripts/generate-build-info.js` on prebuild/predev;
contains `sha`, `buildNumber` (count of commits), `date`, last 5 subjects — shown in About with full sha + build number.

## 3. Changelog fetch (optional)

When online: Worker changelog pull renders latest 30 entries; offline: bundled snapshot only.

## 4. Team page

`src/data/team.json` — names, roles, photo, email; purely static; PRs welcome.
