# Changelog & About — Overview (walkthrough)

> **In one line:** who built this, what does it do, what changed — all visible, never hidden.

1. **Settings → About** — app logo, version (build # + sha), license summary
2. **Changelog** — latest 30 updates with dates and notes
3. **Team** — every contributor with photo and handle; PRs credited
4. **Tech stack** — framework list + why amazeui exists
5. **Support checklist** — screenshot, build sha, request/confirm reference code — all listed here

Hit Settings → About → Change Log to verify you're running what you think you're running.
