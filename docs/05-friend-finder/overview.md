# Friend Finder — Overview (walkthrough)

> **In one line:** "find other students in my course" — verified, class-id matched, privacy-first.

Flow:

1. **Landing** explains the value; CTA = "I already have a handle from class"
2. **Sign in** with VTOP (modal over the page)
3. **Pick your course** — the list comes from the same CSV-driven catalog
4. **See classmates** — sorted by shared courses, branch, degree
5. **Pair** directly from results → becomes the in-app social grant

Everything ships as one public route (`/friend-finder`) plus `/friend-finder/disclaimer` for liability.
